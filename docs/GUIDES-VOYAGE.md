# Guides voyage and connected plan

/guides now presents five connected decisions as a harbour departure: protection/cargo, platform/vessel, connectivity/passage, recovery/rough water, and cost/voyage accounting. A crane, numbered containers, vessel and lighthouse share the site's marine palette. The suggested sequence is local to this page; the standalone guides remain independently available. Hover or keyboard focus aligns the crane with the corresponding guide. There is no continuous ambient animation.

## Connected tools

“Build my cloud plan” opens the five existing calculators in the page. Their model functions remain authoritative. Small publication/reset adapters in the existing controllers expose typed results through guide-results.ts; a WeakMap retains the latest result for initialisation order, and bubbling events update the journey. Each calculator appears once. ChooserQuestion IDs are namespaced to prevent cross-tool label collisions. Embedded mode removes onward-guide offers and the repeated compliance explainer while retaining the calculator's full questions and result.

The compliance stage requires an explicit scope selection. Outside or unconfirmed Slovak ISVS scope is recorded as **Not assessed**, with an unresolved classification requirement and a dimmed cargo container. It never invents a U level or claims EU-wide compliance. Applicable ISVS results include mandatory and recommended measures with references. Platform snapshots retain rankings, chosen answers, tie/close cautions, workload notes and exit advice. All three planning briefs retain answers, priorities and unresolved gaps.

A result is recorded only when the reader chooses to add it. The page then shows the ship and updated manifest at a checkpoint before continuing. Earlier answers can be revisited. Changing a stage removes its recorded result and all later recorded results, but keeps later form answers for review. Reset clears all five tools, scope, artwork, checkpoints and results. A text download includes the combined results and unresolved items. State lasts only while this page remains open; there is no network submission or persistent storage.

The assembled illustration means a planning brief has been prepared. It does not assert that the separate choices have passed engineering validation, a workload trial or compliance approval. This limitation is visible in the page.
